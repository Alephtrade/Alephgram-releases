# Alephgram desktop releases

Official Alephgram desktop installers and update metadata. This repository contains no application source code or credentials.

[Download the latest release](https://github.com/Alephtrade/Alephgram-releases/releases/latest)

- **Windows x64:** download the Setup EXE and install Alephgram. Installed builds check for updates on every launch and can install them automatically.
- **macOS Intel / Apple Silicon:** download the universal DMG and move Alephgram to Applications. Current builds check for new versions; installation is manual until Developer ID signing is configured.
- **Linux x64 / ARM64:** download the matching AppImage, make it executable and launch it. AppImage builds check and install updates on launch.

If you used the older Windows portable EXE, switch to the Setup installer once to enable automatic installation of future updates.

SHA256SUMS contains checksums for the release assets. Workspaces require a corporate Aleph ID account.
